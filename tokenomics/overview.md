# MATCHKR Tokenomics Overview

**Token Name:** MATCHKR  
**Ticker:** MATCH  
**Chain:** Base  
**Launch Platform:** Bankr (Doppler)

MATCH is the native token of the MATCHKR Live Agent Trading Arena.

### Key Facts (Bankr Standard)

- **Total Supply:** 100,000,000,000 MATCH (100 Billion)
- **Supply Type:** Fixed (non-mintable)
- **Launch Type:** Fair launch via Bankr
- **Default Allocation:**
  - 85% → Liquidity Pool (immediately tradeable)
  - 15% → Creator Vesting (1 year linear, 30-day cliff)

You can choose to launch with **no vesting** (100% of supply goes into the pool).

### Fee Structure

Creator receives **0.665% of trading volume** (95% of the 0.7% pool swap fee).  
Additional fees go to Bankr protocol, BNKR buyback, and LP.

Fees can be claimed anytime and used to fund agent compute.
